🧭 O método de um especialista virando seu mentor no Claude Code

Quando a IA ensina, ela explica demais ou de menos, parece certa sem estar, supõe sem avisar e responde com conhecimento genérico. Neste curso você monta um mentor: um agente do Claude Code que ensina no método de um especialista, constrói junto com você e só diz "funciona" depois de rodar.

Copia o método, não a pessoa. Cada regra do mentor aponta para um trecho real do que o especialista publicou, conferido por script. Tudo com o kit aberto da comunidade INEMA e o piloto real que o testou.

O que você vai construir

Um mentor de verdade, para um especialista que você escolhe, numa pasta de projeto do Claude Code. São quatro peças, e cada uma tem um script que diz se ela está pronta.

📚

Acervo + wiki

Tudo o que o especialista publicou, coletado com rastreio e compilado numa wiki interligada que a IA consulta sem se perder.

Regras com prova

Cada regra de conduta tem citação e localizador. Uma citação inventada reprova no validador.

validar_citacoes.py → exit 0

🔁

Loop obrigatório

Definir pronto → menor versão → prever → rodar → mostrar a versão quebrada → relatório por regra.

validar_resposta.py → exit 0

🔒

Portão de execução

Um hook impede o turno de terminar quando houve código escrito e não executado. Vale também para subagentes.

bloqueio + liberação demonstrados

Novo aqui? Um mentor, neste curso, é um subagente do Claude Code com regras próprias e três skills de uso: /<slug>-ensina (ensina construindo junto), /<slug>-revisa (revisa um arquivo seu em 5 seções) e /<slug>-ingere (põe material novo do especialista na wiki). Hook é um script que o Claude Code roda sozinho em certos momentos, como no fim de um turno. Os termos são explicados de novo, com calma, na primeira vez que aparecem em cada módulo.

A lição central

No teste 2, mesmo com a instrução explícita "escreva a previsão antes de rodar", o mentor previu só no raciocínio e escreveu "a previsão bateu" depois. A sessão disse "o validador passa", mas tinha rodado o validador sem o log.

Instrução não basta: precisa de mecanismo (o portão de previsão, que o kit 1.3 trouxe) e de verificação de fora (o validador lendo o log da sessão). Na rodada 4, o portão negou a execução, o mentor escreveu a previsão e o validador com o log aprovou: 5/5.

Cada falha do piloto virou correção no kit, e você vê cada uma delas, com o antes e o depois, nos módulos.

Antes de começar

✓ Você precisa de

  • ✓Claude Code no básico: abrir numa pasta, conversar e rodar um comando.
  • ✓Python 3.10 ou mais novo e git. Os scripts do kit usam só a biblioteca padrão.
  • ✓Um especialista para estudar, com 20 a 50 fontes públicas (cerca de 50 mil palavras). Pode ser você mesmo, se publica conteúdo.
  • ✓Opcional: yt-dlp para legendas de vídeo e um transcritor local para vídeos sem legenda.

✗ Este curso não é

  • ✗Para quem nunca abriu o Claude Code. Comece por um curso introdutório e volte.
  • ✗Clone de voz ou imitação de pessoa. O mentor copia o método, não a persona.
  • ✗Dependente de API paga. Coleta por legenda, transcrição local e exportação manual resolvem.
  • ✗Leitura passiva. Toda aula termina com uma tarefa e um comando que diz se você acertou.
